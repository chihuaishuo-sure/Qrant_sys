# 03 · PRD 评审意见与修正版 v1.1

> 评审人视角：资深量化分析师。原则：**一个让你“看起来赚钱”的回测，比没有回测更危险。**

## 一、评审意见（问题 → 风险 → 修正）

| # | v1.0 的问题 | 会导致的损失/错误 | v1.1 修正 |
|---|---|---|---|
| R1 | 未规定成交时点 | 用当日收盘算信号又按当日收盘成交 = **前视偏差**，回测虚高 | 收盘出信号，**次日开盘成交** |
| R2 | 只写了“含手续费” | 忽略最低 5 元佣金、卖出印花税、整手、涨跌停，小资金回测严重失真 | 完整 A 股成本模型；**涨停买不进、跌停卖不出**；100 股整手；ETF 免印花税 |
| R3 | F7“一键最优参数” | 在全样本上选参数是**过拟合的头号来源** | 删除“最优参数”；改为 **Walk-Forward 样本外检验 + 参数敏感性热力图 + Deflated Sharpe** |
| R4 | 止损默认按止损价成交 | A股跳空低开时实际成交价更差，低估亏损 | 止损触发后**按次日开盘价**成交（含跳空） |
| R5 | 目标“回撤 ≤ 买入持有 60%” | 只要常年半仓就能做到，是**伪优势** | 新增 **“同等平均仓位基准”**：风控策略必须在 Calmar 上同时战胜买入持有和同仓位恒定持有，才算有真实择时价值 |
| R6 | 波动率目标未设上限 | 低波动期可能推导出 >100% 仓位（加杠杆） | 仓位上限 100%，**个人不加杠杆** |
| R7 | 回撤熔断无恢复规则 | 熔断后永远空仓或频繁开关 | 熔断后冷却 N 日 **且** 价格回到均线上方才恢复；界面展示熔断的收益代价 |
| R8 | 个股回测 | 当前股票池存在**幸存者偏差** | 默认标的为宽基/商品/债券 ETF；个股回测加偏差提示 |
| R9 | 指标缺少尾部与“痛苦度” | 夏普无法刻画持续回撤的煎熬 | 增加 CVaR(95%)、Ulcer 指数、最长水下天数、月度收益热力图 |
| R10 | 回撤风险只看一条历史路径 | 历史只是一种可能 | **块自助法蒙特卡洛**模拟未来回撤分布（保留波动聚集） |
| R11 | 信号面板未注明数据日期 | 数据没更新时给出过期信号 | 每条信号显示数据截止日，过期 >3 个交易日标红 |
| R12 | AKShare 单一接口 | 接口变更即全站不可用 | 东财 → 新浪 多源回退 + 本地缓存 + CSV 导入 |
| R13 | 组合仅等权/反波动率 | 熊市中所有资产同时下跌时仍满仓 | 组合内每个资产独立做趋势过滤（Faber GTAA 思路），空仓部分转现金 |
| R14 | 缺少个人纪律工具 | 系统再好，人不执行也会亏 | 仓位计算器 + “交易前检查清单” + 账户亏损红线 |

## 二、PRD v1.1（修正后）

### 2.1 产品定位
**“先求少亏”的个人量化风控工作台**：只出信号、人工下单；每一个“优势”都必须在样本外、扣费后、对比同等仓位基准后成立。

### 2.2 验收标准（KPI）
1. 回测无前视：信号 t 日收盘，成交 t+1 日开盘（单元测试覆盖）
2. 默认风控方案在主流宽基 ETF 上：最大回撤显著低于买入持有，**Calmar 同时高于买入持有与同等平均仓位基准**（系统内实时显示是否达标）
3. Walk-Forward 样本外结果在界面中与样本内并列展示
4. 非程序员：双击 `启动.bat` → 浏览器自动打开 → 3 次点击完成回测

### 2.3 功能清单（v1.1）

| 模块 | 内容 | 优先级 |
|---|---|---|
| 数据 | AKShare 东财/新浪双源、本地缓存、CSV 导入、离线演示数据（明确标注“模拟”） | P0 |
| 策略 | 均线趋势、时间序列动量、唐奇安突破、RSI 回归（带趋势过滤）、买入持有 | P0 |
| 风控层 | 波动率目标（≤100%）、大盘趋势过滤、ATR 跟踪止损（跳空按开盘成交）、回撤熔断（冷却+恢复条件） | P0 |
| 回测引擎 | 次日开盘成交、A股成本、整手、涨跌停、T+1 | P0 |
| 对比 | 买入持有 / 裸策略 / 风控策略 / 同等平均仓位基准 四线对比 | P0 |
| 指标 | 年化、波动、夏普、索提诺、最大回撤、Calmar、CVaR95、Ulcer、最长水下、胜率、换手、平均仓位 | P0 |
| 组合 | 反波动率配置 + 单资产趋势过滤 + 组合波动目标，月度再平衡 | P0 |
| 稳健性 | Walk-Forward、参数敏感性热力图、Deflated Sharpe、块自助蒙特卡洛 | P0 |
| 今日信号 | 自选 ETF 的目标仓位、市场状态（进攻/防守）、数据日期 | P0 |
| 个人风控 | 仓位计算器、交易前检查清单、VaR 估算 | P1 |
| 界面 | Streamlit + Plotly 深色主题、中文、红涨绿跌 | P0 |

### 2.4 明确不做
自动下单、杠杆、分钟级、机器学习“黑箱”选股、承诺收益。

### 2.5 风险声明
本系统是风险管理与研究工具，不构成投资建议。任何历史回测都不保证未来收益；趋势策略在震荡市会出现连续小额亏损，这是换取“避开大跌”的成本。
