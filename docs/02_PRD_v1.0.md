# 02 · PRD v1.0 —— Qrant 个人量化风控系统（初稿）

## 1. 背景与目标
个人投资者亏损的主要来源是：熊市中满仓扛跌、单笔亏损失控、重仓单一资产、凭感觉追涨杀跌。
**Qrant 的目标：用可验证的量化规则，在尽量保留收益的前提下显著降低回撤。**

| 目标 | 指标 |
|---|---|
| 少亏 | 风控后最大回撤 ≤ 买入持有的 60% |
| 不白忙 | 风控后 Calmar（年化收益/最大回撤）高于买入持有 |
| 易用 | 非程序员 5 分钟内完成一次回测；双击启动 |

## 2. 用户画像
- 有 A 股账户的个人投资者，主要交易 ETF 与少量个股
- 会用电脑，不一定会写代码
- 痛点：不知道何时该降仓、单笔该买多少、策略是不是“回测幻觉”

## 3. 功能需求

| 编号 | 功能 | 说明 | 优先级 |
|---|---|---|---|
| F1 | 数据获取 | AKShare 获取 A股/ETF/指数日线（前复权），本地缓存；支持导入 CSV | P0 |
| F2 | 策略库 | 双均线趋势、时间序列动量、唐奇安突破、RSI 均值回归、买入持有 | P0 |
| F3 | 风控层 | 波动率目标仓位、大盘趋势过滤、ATR 跟踪止损、回撤熔断 | P0 |
| F4 | 回测引擎 | 计算净值、交易记录，含手续费 | P0 |
| F5 | 绩效与风险指标 | 年化收益、波动、夏普、索提诺、最大回撤、Calmar、胜率、VaR | P0 |
| F6 | 多资产组合 | 等权 / 反波动率配置，月度再平衡 | P1 |
| F7 | 参数优化 | 网格搜索给出最优参数 | P1 |
| F8 | 今日信号面板 | 对自选列表输出“持有/空仓/减仓”信号 | P0 |
| F9 | 仓位计算器 | 按单笔风险（如 1%）与止损价计算可买股数 | P1 |
| F10 | 美观界面 | Streamlit + Plotly，深色金融风格 | P0 |

## 4. 非功能需求
- 纯 Python，依赖少；Windows 双击 `启动.bat` 运行
- 单标的 10 年日线回测 < 1 秒
- 网络失败时可用缓存/演示数据

## 5. 不做（v1.0）
- 自动下单 / 券商接口
- 分钟级、高频
- 机器学习选股

## 6. 风险提示
回测不代表未来；系统不构成投资建议。
